SUPPORT · ROGUELIKE 贪吃蛇

发现了 bug？有好点子？

联系我们最快的方式是在 GitHub 上提交 issue。欢迎反馈 bug、提出功能建议或询问规则。请告诉我们发生了什么，以及你原本的预期。

常见问题

一局是怎么进行的？在地图上选择路线。每一关都是不同类型的游戏；通关后选择一张升级卡。撞上就会失去一条蛇，失去最后一条，这一局就结束了。

经典和现代有什么区别？两者都是无尽模式：一个棋盘，没有尽头，挑战最高分。现代模式有跳跃和道具，经典模式就是你记忆中的贪吃蛇。

怎么跳跃？点击“跳”按钮，蛇就会跃过自己的身体。

我的分数保存在哪里？保存在你的设备上，如果已登录，也会保存在你的 iCloud 账户中。登录 Game Center 即可让最高分登上全球排行榜。
