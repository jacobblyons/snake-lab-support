PRIVACY · 스네이크 로그라이크

요약: Snake Lab은 개인 데이터를 수집하지 않습니다. 광고와 계정이 없습니다. 게임 개선에 도움이 되는 익명 플레이 통계를 전송합니다.

앱이 수집하는 정보

개인 데이터는 수집하지 않습니다. 광고와 계정이 없습니다. 게임 기록, 점수, 해금 항목, 설정은 기기에 저장됩니다. 앱이 저희에게 보내는 것은 아래에 설명된 익명 플레이 통계뿐입니다.

익명 플레이 통계

어떤 스테이지가 너무 어려운지, 어떤 업그레이드가 선택되는지, 한 판이 얼마나 이어지는지 알기 위해 앱은 짧은 플레이 기록을 전송합니다. 앱을 열고 닫은 시점, 선택한 모드와 방, 고른 카드, 클리어한 스테이지, 각 뱀을 잃은 이유, 점수와 시간이 포함됩니다. 각 기록에는 앱 버전, iPhone 모델, iOS 버전, 게임 언어, 휴대폰의 지역 설정도 함께 담깁니다.

기록에는 앱을 설치할 때 만들어지는 무작위 번호가 붙으며, 이를 통해 몇 명이 플레이하는지 알 수 있습니다. 이 번호는 이름, Apple ID, Game Center 계정, 광고 식별자, 위치와 연결되지 않으며, IP 주소도 기록되지 않습니다. 앱을 삭제하면 번호도 사라집니다. 기록은 Microsoft Azure Application Insights에 저장되고 90일 후 삭제되며, Snake Lab 개선에만 사용됩니다. 판매되거나 공유되지 않으며 광고나 추적에 사용되지 않습니다.

ICLOUD

iCloud에 로그인되어 있으면 점수와 해금 항목이 다른 기기에서도 이어지도록 본인의 iCloud 계정에 보관됩니다. Apple이 Apple의 개인정보 처리방침에 따라 보관하며, 저희는 볼 수 없습니다.

GAME CENTER

Apple의 Game Center에 로그인하면 최고 점수가 Apple의 개인정보 처리방침에 따라 Apple의 순위표 서비스로 전송됩니다. 저희는 Game Center 계정을 볼 수 없습니다.

어린이

이 앱은 모든 연령에 적합하지만 어린이를 대상으로 하지는 않습니다. 누구의 개인 데이터도 수집하지 않습니다.
