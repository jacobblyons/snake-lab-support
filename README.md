# Snake Lab support

Support site and privacy policy for the iOS game Snake Lab, served from `docs/` by GitHub Pages in 13 languages.

- Home: https://jacobblyons.github.io/snake-lab-support/
- Support: https://jacobblyons.github.io/snake-lab-support/support.html
- Privacy: https://jacobblyons.github.io/snake-lab-support/privacy.html

Bug reports, ideas and questions: [open an issue](https://github.com/jacobblyons/snake-lab-support/issues/new/choose).

The pages are generated by `tools/make_site.py` (its table holds every language's words); `docs/style.css` is the look.
